# Амбервейл

**Сократівська симуляція клінічного розслідування**

Студент-медик потрапляє в домодерний фентезійний світ — і зустрічає спалах хвороби. Штучний інтелект (Claude) грає роль майстра оповіді: ставить запитання, не дає відповідей і вимагає пояснень на кожне рішення. Студент розслідує, формулює гіпотезу і захищає діагноз перед радою старійшин.

Фентезійний світ. Справжня наука.
